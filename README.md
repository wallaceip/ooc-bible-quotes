# Bible Quotes App

A clean, responsive React application designed to display, search, and bookmark inspirational Bible verses and quotes for daily reflection.

## Features

- **Daily Verse & Quotes:** Browse curated and inspirational scripture verses.
- **Search & Filter:** Easily look up verses by keywords, books, or specific topics.
- **Favorites / Bookmarks:** Save meaningful quotes to your local favorites list for quick access.
- **Responsive Design:** Optimized for seamless usage across desktop, tablet, and mobile devices.

## Tech Stack

- **Frontend Library:** React (JSX, Hooks)
- **Styling:** Modern CSS / Component Styles
- **Build Tool:** Vite / Create React App
